# piano tile

An automatic solver for the game “Piano Tiles” is a program or script designed to detect the falling tiles on the screen and simulate quick, precise clicks or taps at the correct positions.
It typically uses techniques like image processing or screen coordinate tracking to identify black tiles in real time, then sends automated input events (mouse clicks or keyboard strokes) to “press” them instantly.
Such a solver can achieve perfect accuracy and very high speed, often far beyond human reaction time.
